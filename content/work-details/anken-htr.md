## Project Details

● オフィス移転支援プラットフォームサイトの新規デザイン・UI/UX改善・フロントエンド実装

![Project Details thumbnail](/assets/experience/th-exp-htr-01.png){width=400 height=150}
[関連サイトを見る](https://hataraba.com/)

- オフィス移転支援プラットフォームサイトの開発プロジェクトにおいて、IA設計、UIデザイン制作、フロントエンド実装までを一貫して担当しました。

- 初期版は短期間でローンチされていたため、デザイン面やユーザー体験に改善余地がある状態でした。プロジェクト参画後は、オフィス移転を検討するユーザーの課題や検討プロセスを踏まえ、サービスの魅力が伝わるUI設計へ改善。他社サービスと比較した際の機能性、検索体験のわかりやすさ、エンジニアリング面での実現性も考慮しながら、デザイン設計を主導しました。

- ログイン機能やデータベース連携を前提とした仕様を踏まえ、画面設計からフロントエンド実装までを担当。見た目の改善だけでなく、サービスとしての使いやすさや運用しやすさを意識した開発に貢献しました。

## Outcome

- フロントページ全体のレイアウト設計、ワイヤーフレームからモックアップ作成、プロトタイピング、ユーザーペルソナ設計、IA設計、ブランドイメージの反映までを実施。
- PC・スマホ双方のレスポンシブデザイン対応 / コントラストや識字率などアクセシビリティに配慮したデザイン調整 / Core Web Vitals（CLS）改善など。
- メインビジュアル制作（社内コンペによる選定）、各種バナー作成も担当。
- EJSテンプレートエンジンでのフロント実装、DockerやNode.jsと連携させ、Ruby on Railsと通信して動的検索UIを構築。
- チーム内でコードレビューや成果物のレビューを頻繁に実施し、リードエンジニアやバックエンドエンジニアから技術フィードバックを受けながら品質向上を推進。
- QAフェーズ後のバグ修正、技術的改善・パフォーマンス最適化にも積極的に対応。
- ハイブリッド型開発、チーム内レビュー体制、役員レビュ―有。
